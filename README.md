# CBA: Clumsy Bear's Adventure
### 엉뚱곰 엉춤 대모험

> 엉뚱한 곰이 마법의 샘을 향해 떠나는 2D 텍스트 선택지 어드벤처.
> 플레이어의 선택은 확률에 지배되어, 같은 선택도 매번 결과가 달라집니다.

---

## 게임 소개

얼렁뚱땅 곰이 마법의 샘을 향해 나아가는 여정을 다룬 텍스트 선택형 어드벤처 게임입니다.
복잡한 전투 없이 선택지와 확률만으로 긴장감을 만들어냅니다.
실패해도 엔딩이 쌓이고, 그 엔딩을 수집하는 재미로 다시 플레이하게 되는 구조입니다.

---

## 플레이 방법

1. **게임 시작** 버튼을 클릭합니다.
2. 이벤트가 발생하면 **선택지 2개** 중 하나를 선택합니다.
3. 선택 결과는 **확률로 결정**됩니다. 같은 선택지도 매번 결과가 달라질 수 있습니다.
4. **Next** 버튼으로 다음 이벤트로 넘어갑니다.
5. **기본체력(빨간 ♥ 3칸)** 이 모두 사라지면 게임 오버입니다.
6. **16턴** 을 생존하면 17턴에 마법의 샘에 도달하고 진엔딩을 볼 수 있습니다.

### 특수 이벤트
| 턴 | 이벤트 | 설명 |
|----|--------|------|
| Turn 7 | 벌끔이 | 방해꾼 벌과의 조우 |
| Turn 11 | 모자 이벤트 | 선택 결과가 다음 이벤트에 영향을 줌 |
| Turn 12 | 곰순이 | 엉뚱곰이 보다 행복한 모험을 하게 됨 |
| Turn 17 | 마법의 샘 | 진엔딩 + 엉덩이춤 해금 |

### 엔딩 도감
플레이할 때마다 결과가 엔딩 도감에 기록됩니다. 타이틀 화면에서 확인할 수 있습니다.

## 기술 스택

- **Engine** : Unity 6 (6000.3.13f1)
- **Language** : C#
- **Platform** : Mobile (1080×1920)
- **Data** : Excel → JSON 데이터드리븐 파이프라인
- **Save** : PlayerPrefs

---

## 핵심 구현 포인트

**데이터드리븐 파이프라인**
이벤트 텍스트, 선택지, 확률, 결과를 전부 엑셀로 관리합니다. 코드 수정 없이 엑셀만 수정해서 게임 밸런스와 텍스트를 조정할 수 있는 구조로 설계했습니다.

**특수 이벤트 시스템**
벌끔이, 모자, 곰순이는 고정 턴에 등장하는 다단계 스텝 구조입니다. 이전 이벤트의 선택 결과가 다음 이벤트 분기에 연동되며, `IsInSpecialEvent` 플래그 하나로 일반/특수 이벤트를 분리해 같은 UI를 재사용했습니다.

**수집형 엔딩 시스템**
실패 엔딩도 콘텐츠가 되도록 설계했습니다. 플레이할 때마다 엔딩 기록이 누적되고 도감으로 확인할 수 있어 리플레이어빌리티를 유도합니다.
